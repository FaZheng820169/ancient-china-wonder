# Ancient China Wonder

**A universe of gods, ghosts, fox spirits and wonders from ancient China.**

Repository: https://github.com/FaZheng820169/ancient-china-wonder · Live: https://ancient-chinawonder.vercel.app

Ancient China Wonder is an independent content site that collects, translates and systematises
classical Chinese **zhiguai** (志怪, "tales of the strange") into one coherent fantasy universe —
for fantasy readers, mythology lovers and TTRPG designers.

## What's inside

| Section | Content |
| --- | --- |
| `/stories` | 208 classical tales translated from the public-domain originals (Liaozhai, Tang chuanqi, Soushen Ji, Youming Lu, Yuewei Caotang Biji, Zibuyu and Xu Zibuyu, Yijian Zhi, Xieduo, Shan Hai Jing…), each with the original Chinese text, cultural notes, a custom illustration and source data |
| `/worldview` | A 25-entry encyclopedia of the shared universe: the three realms, gods vs immortals, ghosts, hun and po, how souls move on, how a god gets a post, how a shrine gets built, the small gods, the Courts of the Dead, Fengdu, the forgetting brew of Meng Po, the underworld examination, how time runs in the otherworld, karma as an accounting system, how to file a document with a god, marriage across the human border, fox spirits, why these tales refuse to end, cultivation rules, key figures |
| `/worldview/timeline` | An interactive timeline of the universe, from the creation myths to Pu Songling |
| `/features` | 15 long-form essays (fox-spirit evolution, history of the underworld, Shan Hai Jing bestiary, the birth of wuxia, the economy of the afterlife, what a Chinese ghost can and cannot do, the rules of borrowed bodies, the price of immortality, the instrument cabinet, women and the strange, the scholar and the strange, hungry ghosts and otherworldly food, the dream is a country, how to sue a god, how ghost-story writers claimed to know) |
| `/guides` | New-reader guides: what zhiguai is, the map of the universe, key concepts, translation method, and a field guide to the source collections |
| `/search` | Full-text search (Pagefind, static index generated at build time) |
| `/rss.xml` | RSS 2.0 feed of the 40 most recent tales |

## Tech

- [Astro 5](https://astro.build) static site, content collections (Markdown + Zod schemas)
- No database, no backend, no user accounts — fully static
- Pagefind for build-time full-text search
- RSS 2.0 feed, sitemap, and JSON-LD (`Article` + `BreadcrumbList`) on every story and worldview page
- Vercel Web Analytics (cookieless, aggregate page views only)
- Hand-rolled CSS design system (warm paper `#F7F5F0`, cinnabar `#A62C21`, pine green `#2D5016`)
- Illustrations: AI-generated ink-wash, labelled as such on every page

## Develop

```bash
npm install
npm run dev        # local dev server
npm run build      # builds to dist/ and generates the Pagefind search index
```

## Deploy

Deployed on [Vercel](https://vercel.com) as a static Astro site (project `ancient-chinawonder`,
framework auto-detected). The search index is generated by the `postbuild` script.

CI: `.github/workflows/deploy.yml` deploys to production on every push to `main`, using the
repository secret `VERCEL_TOKEN`.

## Content policy

- All source texts are public domain (authors dead for centuries)
- All English translations, notes, essays and entries are **original work**, made directly from the
  classical Chinese — never adapted from existing translations
- See `src/pages/translation-policy.astro` for the working rules
